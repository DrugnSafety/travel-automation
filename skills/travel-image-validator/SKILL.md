# Travel Image Validator v3

삽입된 이미지를 **2중 검증**한다: ① URL이 살아있는가(접근성) ② 내용이 그 장소가 맞는가(관련성).
v2는 ①만 검증해서 "멀쩡히 뜨는 엉뚱한 사진"을 통과시켰다. v3의 핵심 추가가 ②다.

## 검증 1: 접근성 (HTTP)

Notion 첨부 업로드(`file-upload://`)로 삽입된 이미지는 **이 단계 스킵** (Notion 호스팅 = 깨질 수 없음).
외부 URL embed만 검사:

```bash
curl -sI -o /dev/null -w "%{http_code} %{content_type}" --max-time 5 "{image_url}"
```

| 결과 | 판정 |
|------|------|
| `200 image/*` | ✅ 통과 → 검증 2로 |
| `200 text/html` | ❌ 이미지 아님 → 교체 |
| `301/302` | ⚠️ Notion에서 깨질 수 있음 → 최종 URL로 교체 |
| `403/404/000` | ❌ 교체 |

## 검증 2: 관련성 (시각 판독 — v3 신규)

각 이미지를 다운로드해 **Read 도구로 직접 열어** 판정한다:

```bash
mkdir -p /tmp/img_validate && curl -sL --max-time 15 -o /tmp/img_validate/{spot}.jpg "{URL}"
```

판정 기준 (스팟 이름·유형과 대조):
```
□ 피사체 일치: 사진 속 지형/건물/간판이 {스팟명}의 알려진 특징과 일치하는가
  예) Antelope Canyon → 슬롯캐년의 물결 사암 벽. 일반 사막 사진이면 FAIL
□ 장소 유형 일치: 식당 섹션에 풍경 사진, 폭포 섹션에 도시 사진 등 유형 불일치 여부
□ 품질: 심한 블러, 워터마크, 저해상도(<800px), 극단적 크롭
□ 부적절 요소: 무관한 인물 클로즈업, 텍스트 오버레이 광고
```

판정이 애매하면(특징이 뚜렷하지 않은 장소) Commons 파일명·출처 문서로 교차 확인하고, 그래도 불확실하면 `uncertain`으로 보고서에 기록한다 — 임의 통과 금지.

## 교체 절차

FAIL 이미지는 travel-image-search v3 절차(위키피디아 1순위 → 시각 검증 → 첨부 업로드)로 재확보해 교체한다:

1. 대체 이미지 확보 + 시각 검증 통과 확인
2. `notion-create-attachment`로 업로드 → `markdown_source` 획득
3. `notion-update-page` update_content: `old_str`=기존 이미지 마크다운, `new_str`=새 이미지 마크다운
4. 페이지 재fetch로 반영 확인
5. 3회 실패 시 이미지 제거(텍스트 유지) 후 보고서에 기록

## 실행 모드

- **파이프라인 모드**: travel-image-search가 남긴 `/tmp/{여행지}_images.json`을 입력으로 받아, `visual_check: pass` 기록이 있는 항목은 접근성만 재확인(중복 판독 방지), 기록 없는 항목만 전체 검증.
- **독립 모드 (기존 페이지 사후 점검)**: 사용자 지정 Notion 페이지를 fetch → 서브 페이지 포함 모든 `![...](...)` 추출 → 전수 2중 검증. 페이지가 많으면 Agent tool로 페이지별 병렬 분배.

## 검증 보고서

```markdown
## 🔍 이미지 검증 결과
- 총 {N}장 | ✅ 통과 {N} | 🔄 교체 {N} (접근성 {n} / 관련성 {n}) | ❓ 판정보류 {N} | ❌ 해결불가 {N}

| 페이지 | 스팟 | 문제 | 조치 |
|--------|------|------|------|
| Day 2 | Antelope Canyon | 관련성 FAIL (일반 사막 사진) | Wikipedia 대표 이미지로 교체 + 첨부 업로드 |

### 사용자 확인 요망
- {uncertain 항목: 스팟명 + 판단 근거 + 현재 이미지 썸네일 링크}
```

## 오류 처리

| 상황 | 대응 |
|------|------|
| Notion fetch 실패 | 3회 재시도 후 해당 페이지 스킵·기록 |
| 다운로드 실패(핫링크 차단) | 접근성 FAIL로 분류 → 교체 |
| update_content 매칭 실패 | 페이지 재fetch → 짧은 고유 문자열로 재시도 |
| 모든 대체 후보 실패 | 이미지 제거, travel-image-generator 제안 |
