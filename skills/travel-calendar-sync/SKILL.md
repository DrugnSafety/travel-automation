# Travel Calendar Sync

여행 일정 정보를 Google Calendar에 자동으로 등록하는 스킬입니다.

## 필요 도구

- **Google Calendar MCP**: `gcal_create_event`, `gcal_list_events`, `gcal_list_calendars`, `gcal_update_event`, `gcal_delete_event`
- **Gmail MCP** (선택): `gmail_search_messages` — 비행기 예약 이메일 검색
- 입력: 여행 일정 정보 (Notion 페이지 또는 마크다운)

## 이벤트 유형

### 1. 이동 이벤트 (🚗 / ✈️)

```
제목: 🚗 {출발지} → {도착지} ({거리}, {소요시간})
시간: {출발 시간} ~ {도착 시간}
위치: {경로 또는 공항}
설명: - 거리: {km}
      - 예상 소요: {시간}
      - 경유: {경유지 정보}
색상: 바나나 (노랑)
```

### 2. 관광 이벤트 (📍)

```
제목: 📍 {스팟명}
시간: {시작} ~ {종료}
위치: {주소}
설명: - 입장료: ${금액}
      - 난이도: {레벨}
      - 팁: {주요 팁}
      - Notion 링크: {페이지 URL}
색상: 세이지 (초록)
```

### 3. 식사 이벤트 (🍽️)

```
제목: 🍽️ {식사 유형} — {레스토랑명}
시간: {시작} ~ {종료}
위치: {레스토랑 주소}
설명: - 추천 메뉴: {메뉴}
      - 가격대: ${범위}
      - 예약: {필요/불필요}
색상: 토마토 (빨간)
```

### 4. 숙소 이벤트 (🏨)

```
제목: 🏨 {숙소명} 체크인/체크아웃
시간: 종일 이벤트 또는 특정 시간
위치: {숙소 주소}
설명: - 예약번호: {번호}
      - 체크인: {시간}
      - 체크아웃: {시간}
색상: 그레이프 (보라)
```

### 5. 비행 이벤트 (✈️)

```
제목: ✈️ {항공편} {출발공항}→{도착공항}
시간: {출발 시간} ~ {도착 시간} (시간대 고려)
위치: {공항명}
설명: - 항공사: {항공사}
      - 편명: {편명}
      - 터미널: {터미널}
      - 게이트: {게이트}
색상: 블루베리 (파랑)
```

## 워크플로우

### Step 1: 캘린더 확인

```
gcal_list_calendars로 사용 가능한 캘린더 목록 확인
→ 기본 캘린더 또는 사용자 지정 캘린더 선택
```

### Step 2: 기존 이벤트 확인

```
gcal_list_events로 여행 기간의 기존 이벤트 확인
→ 충돌 여부 파악
→ 이미 등록된 여행 이벤트가 있으면 업데이트/삭제 여부 확인
```

### Step 3: 비행 스케줄 검색 (선택)

Gmail에서 비행기 예약 이메일 검색:
```
gmail_search_messages: "flight confirmation" OR "boarding pass" OR "e-ticket"
날짜 범위: 여행 기간 전후
```

### Step 4: 이벤트 생성

일정 순서대로 이벤트를 생성합니다:

```
Day 1: ✈️ 비행 → 🚗 렌트카 → 📍 관광1 → 🍽️ 저녁 → 🏨 체크인
Day 2: 📍 관광1 → 📍 관광2 → 🍽️ 점심 → 📍 관광3 → 🍽️ 저녁
...
```

**시간 배정 기준:**
- 트레일/하이킹: 테이블에 명시된 소요시간 + 여유 30분
- 전망대/뷰포인트: 30분-1시간
- 박물관/미술관: 1.5-2시간
- 식사: 점심 1시간, 저녁 1.5시간
- 이동: 구글맵 기준 소요시간 + 여유 15분

### Step 5: 검증

생성된 이벤트를 `gcal_list_events`로 확인하여:
- 시간 겠침이 없는지
- 이동 시간이 충분한지
- 모든 스팟이 등록되었는지

## 시간대 처리

여행지별 시간대를 올바르게 적용합니다:
- 미국 서부: `America/Los_Angeles` (PST/PDT)
- 미국 동부: `America/New_York` (EST/EDT)
- 한국: `Asia/Seoul` (KST)
- 유럽: 국가별 시간대
- 일본: `Asia/Tokyo` (JST)

비행기 이벤트는 출발지/도착지 각각의 현지 시간으로 설정합니다.

## 일정 업데이트

이미 등록된 여행 캘린더를 업데이트할 때:
1. 기존 이벤트 목록을 가져옵니다
2. 변경된 부분만 `gcal_update_event`로 수정
3. 삭제된 일정은 `gcal_delete_event`로 제거
4. 새로 추가된 일정은 `gcal_create_event`로 생성
