# Travel Presentation

여행 일정표를 기반으로 시각적으로 완성도 높은 PowerPoint 프레젠테이션을 생성하는 스킬입니다.

## 핵심 원칙

- **PowerPoint MCP 도구**를 기본 생성 도구로 사용합니다.
- 각 슬라이드는 **이미지 + 핵심 정보**로 구성하여 시각적 임팩트를 극대화합니다.
- 여행 일정의 흐름이 자연스럽게 이어지도록 날짜별 → 스팟별 순서로 구성합니다.

## 사용 도구

### PowerPoint MCP (기본)

```
사용 가능한 도구:
- create_presentation: 새 프레젠테이션 생성
- add_slide: 슬라이드 추가 (레이아웃 지정)
- set_slide_title: 슬라이드 제목 설정
- add_text_to_slide: 텍스트 추가 (위치, 크기, 서식 지정)
- insert_image: 이미지 삽입 (URL 또는 파일 경로)
- save_presentation: 파일 저장
- export_pdf: PDF로 내보내기
- close_presentation: 프레젠테이션 닫기
```

## 슬라이드 구조

### 1. 표지 슬라이드 (1장)

```
┌──────────────────────────────────────────┐
│                                     │
│   🏜️ {여행 제목}                    │
│   {여행 기간} | {인원 구성}           │
│                                     │
│   [대표 이미지 — 전체 배경]            │
│                                     │
└──────────────────────────────────────────┘
```

- 배경: 여행지 대표 이미지 (Pexels CDN, w=1920)
- 제목: 여행명 + 이모지
- 부제: 기간, 인원, 출발지
- 색상: 어두운 반투명 오버레이 위에 흰 텍스트

### 2. 전체 일정 요약 슬라이드 (1장)

```
┌──────────────────────────────────────────┐
│  📋 전체 일정 Overview               │
│                                     │
│  Day 1  │ 출발 → {도시}              │
│  Day 2  │ {주요 스팟 1}, {스팟 2}     │
│  Day 3  │ {주요 스팟 3}, {이동}       │
│  ...    │ ...                       │
│  Day N  │ 귀가                       │
│                                     │
└──────────────────────────────────────────┘
```

- 테이블 형식 또는 타임라인 레이아웃
- 각 날짜별 1줄 요약 (지역 + 주요 활동)
- 색상 코딩: 이동일(회색), 관광일(포인트색), 귀가일(회색)

### 3. 날짜별 구분 슬라이드 (N장)

각 날짜의 시작을 알리는 구분 슬라이드:

```
┌──────────────────────────────────────────┐
│                                     │
│   Day {N} — {날짜 (요일)}             │
│   📍 {지역명}                        │
│                                     │
│   [해당 지역 대표 이미지]              │
│                                     │
└──────────────────────────────────────────┘
```

### 4. 스팟별 상세 슬라이드 (스팟당 1~2장)

**레이아웃 A: 이미지 좌측 + 정보 우측**

```
┌──────────┬─────────────────────┐
│            │  📍 {스팟명}            │
│  [이미지]   │                        │
│            │  {1-2줄 설명}           │
│            │                        │
│            │  ⏰ 추천 시간: {시간}     │
│            │  💰 입장료: {금액}       │
│            │  📸 포토 팁: {한줄 팁}   │
│            │  ⚠️ 주의: {한줄 주의}    │
└──────────┴─────────────────────┘
```

**레이아웃 B: 이미지 상단 + 정보 하단 (풍경 위주)**

```
┌──────────────────────────────────────────┐
│  [와이드 이미지 — 상단 60%]            │
│                                     │
├──────────────────────────────────────────┤
│  📍 {스팟명}                         │
│  {설명} | ⏰ {시간} | 💰 {비용}       │
│  📸 {포토 팁}                        │
└──────────────────────────────────────────┘
```

### 5. 이동 경로 슬라이드 (날짜간 이동 시)

```
┌──────────────────────────────────────────┐
│  🚗 이동 — {출발지} → {도착지}        │
│                                     │
│  거리: {km}  |  예상 시간: {시간}      │
│  경로: {주요 고속도로/도로}            │
│                                     │
│  💡 Tip: {이동 중 볼거리/휴게소}       │
└──────────────────────────────────────────┘
```

### 6. 맛집 추천 슬라이드 (날짜별 1장)

```
┌──────────────────────────────────────────┐
│  🍽️ Day {N} 맛집 추천               │
│                                     │
│  🥇 {식당명} — {메뉴} (${가격대})     │
│     📍 {위치} | ⭐ {평점}            │
│                                     │
│  🥈 {식당명} — {메뉴} (${가격대})     │
│     📍 {위치} | ⭐ {평점}            │
│                                     │
└──────────────────────────────────────────┘
```

### 7. 마무리 슬라이드 (1장)

```
┌──────────────────────────────────────────┐
│                                     │
│   🎒 준비물 체크리스트 하이라이트       │
│   ⚠️ 긴급 연락처 요약                │
│   📋 예약 확인 필요 항목              │
│                                     │
│   즐거운 여행 되세요! 🌟              │
│                                     │
└──────────────────────────────────────────┘
```

## 디자인 가이드

### 색상 팔레트 (여행 유형별)

| 여행 유형 | Primary | Secondary | Accent | Background |
|-----------|---------|-----------|--------|------------|
| **자연/국립공원** | `2C5F2D` (forest) | `97BC62` (moss) | `F5F5F5` (cream) | `1a1a2e` (dark) |
| **도시 관광** | `1E2761` (navy) | `CADCFC` (ice) | `FFFFFF` (white) | `0f0f23` (midnight) |
| **해변/리조트** | `065A82` (deep blue) | `1C7293` (teal) | `F9E795` (gold) | `0d1b2a` (ocean) |
| **가을 단풍** | `B85042` (terracotta) | `E7E8D1` (sand) | `A7BEAE` (sage) | `2d1810` (bark) |
| **겨울/스키** | `36454F` (charcoal) | `F2F2F2` (snow) | `028090` (ice teal) | `1a1a2e` (night) |

### 폰트 설정

| 요소 | 폰트 | 크기 | 스타일 |
|------|-------|------|--------|
| 표지 제목 | Georgia 또는 Arial Black | 44pt | Bold |
| 슬라이드 제목 | Georgia | 32pt | Bold |
| 본문 | Calibri | 16pt | Regular |
| 정보 라벨 | Calibri | 14pt | Bold + 색상 |
| 캐션/출처 | Calibri Light | 10pt | Italic, muted |

### 이미지 처리

- **Pexels CDN URL** 사용 (travel-image-search 스킬과 동일)
- 슬라이드 배경 이미지: `w=1920` 파라미터
- 스팟 이미지: `w=1280` 파라미터
- 이미지 위에 텍스트: 반투명 검정 오버레이 사용

## 실행 워크플로우

### 입력 요구사항

| 소스 | 정보 |
|------|------|
| 여행 일정표 | 날짜, 스팟, 이동 경로 |
| travel-research 결과 | `/tmp/{여행지}_enriched.md` (있으면 활용) |
| Notion 페이지 | 기존 Notion 가이드의 내용 (있으면 fetch로 가져오기) |
| 사용자 설정 | 디자인 테마, 언어, 포함할 섹션 |

### 생성 절차

```
1. 데이터 수집
   - 일정표 파싱 → 날짜/스팟/이동 목록
   - /tmp enriched.md 파일 확인 (있으면 활용)
   - 기존 Notion 페이지 fetch (있으면 콘텐츠 활용)

2. 이미지 수집
   - 각 스팟별 Pexels 이미지 URL 확보
   - 표지용 대표 이미지 선정
   - 날짜 구분 슬라이드용 지역 이미지 확보

3. PPT 생성 (PowerPoint MCP)
   - create_presentation으로 새 파일 생성
   - 표지 → 전체 일정 → [날짜별: 구분 → 스팟별 → 맛집] → 마무리
   - 각 슬라이드: add_slide → set_slide_title → add_text_to_slide → insert_image

4. 저장 및 전달
   - save_presentation으로 .pptx 저장
   - 사용자 workspace 폴더에 복사
   - 선택적: export_pdf로 PDF 버전도 생성
```

### 슬라이드 수 가이드

| 여행 기간 | 예상 슬라이드 수 |
|-----------|----------------|
| 2-3일 | 15-25장 |
| 4-5일 | 25-40장 |
| 7일 | 40-55장 |
| 10일+ | 55-80장 |

## Notion 데이터 연동

기존 Notion 여행 가이드가 있는 경우, 해당 콘텐츠를 PPT에 반영:

```
1. fetch로 메인 페이지 읽기 → 전체 일정 요약 추출
2. 각 서브 페이지 fetch → 스팟별 상세 정보 추출
3. 6가지 콘텐츠 블록 중 PPT에 적합한 핵심 정보만 선별:
   - 📸 포토 스팟 팁 (1줄)
   - 💰 비용 요약
   - ⚠️ 주의사항 (리뷰 기반, 있으면)
   - 🍽️ 맛집 하이라이트
```

## pptxgenjs Fallback

PowerPoint MCP가 사용 불가할 경우 Node.js pptxgenjs로 생성:

```bash
npm install -g pptxgenjs
```

```javascript
const pptxgen = require("pptxgenjs");
const pptx = new pptxgen();
pptx.defineLayout({ name: "TRAVEL", width: 13.33, height: 7.5 });
pptx.layout = "TRAVEL";

let slide = pptx.addSlide();
slide.addImage({ path: "{pexels_url}", x: 0, y: 0, w: "100%", h: "100%" });
slide.addShape(pptx.ShapeType.rect, {
  x: 0, y: 0, w: "100%", h: "100%",
  fill: { color: "000000", transparency: 50 }
});
slide.addText("{여행 제목}", {
  x: 1, y: 2.5, w: 11, h: 1.5,
  fontSize: 44, fontFace: "Georgia", color: "FFFFFF", bold: true, align: "center"
});
pptx.writeFile({ fileName: "travel-guide.pptx" });
```

## 오류 처리

| 상황 | 대응 |
|------|------|
| PowerPoint MCP 미연결 | pptxgenjs (Node.js) fallback으로 생성 |
| 이미지 삽입 실패 | 텍스트 전용 슬라이드로 대체 |
| 스팟 정보 부족 | 기본 템플릿으로 생성, 수동 입력 안내 |
| 슬라이드 수 초과 (80+) | 주요 스팟만 선별, 나머지는 부록 처리 |

## 출력

- **기본**: `.pptx` 파일 (사용자 workspace 폴더)
- **선택**: `.pdf` 버전 (export_pdf 또는 soffice 변환)
- **파일명**: `{여행명}_가이드_{날짜}.pptx`
