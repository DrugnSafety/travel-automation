# Travel Quality Loop — 감사 · 수정 · 재검증

## 동작 방식

```
      ┌────────────────────────────────────────────┐
      │  1. 전체 페이지 fetch → findings 수집       │
      └────────────────────┬───────────────────────┘
                           ▼
      ┌────────────────────────────────────────────┐
      │  2. findings 를 심각도별 정렬 (S1 > S2 > S3)│
      └────────────────────┬───────────────────────┘
                           ▼
      ┌────────────────────────────────────────────┐
      │  3. 자동 수정 가능한 항목 수정               │
      └────────────────────┬───────────────────────┘
                           ▼
      ┌────────────────────────────────────────────┐
      │  4. 재검증 → 남은 findings 가 0 이면 종료    │
      │     아니면 1번으로 (최대 3회)               │
      └────────────────────────────────────────────┘
```

3회 순환 후에도 남은 항목은 **`report.md`의 "수동 확인 필요"에 기록**하고 종료한다. 조용히 넘어가지 않는다.

## 체크리스트

### S1 — 치명적 (반드시 수정)

**C1. 한글 무결성**

기계 탐지:

```python
import re, json, sys
PATTERNS = {
  "조합용 자모 노출": r'[ᄀ-ᇿꥠ-꥿ힰ-퟿]',
  "대체 문자":       r'�',
  "이스케이프 잔재": r'\\u[0-9a-fA-F]{4}',
  "제어 문자":       r'[\x00-\x08\x0B\x0C\x0E-\x1F]',
}
```

기계 탐지만으로는 부족하다. **형태는 정상 한글인데 의미가 파손된 오류**가 실제 사고의 대부분이었다.

| 파손 | 정상 | 유형 |
|---|---|---|
| 열로스톤 / 옥색 | 옐로스톤 | 고유명사 |
| 통밥집 | 통나무집 | 합성어 |
| 진흥온천 | 진흙온천 | 형태소 |
| 랑저 | 레인저 | 외래어 |
| 밽난로 | 벽난로 | 자모 혼입 |
| 묘샐 | 화석 | 완전 파손 |
| 되우 | 뇌우 | 모음 |
| 만탕 / 저럼 | 만땅 / 저렴 | 된소리·받침 |
| 갈런당 | 갤런당 | 외래어 |
| 그리즘리 | 그리즐리 | 외래어 |

**점검 방법**: 고유명사(지명·시설명·동식물명·외래어)를 추출해 `trip-brief.json` 및 리서치 원문의 표기와 대조한다. 페이지 전체를 눈으로 읽는 것이 가장 확실하다.

**수정**: `replace_content`로 해당 페이지를 재작성한다. 한글은 문자 그대로 입력한다.

---

**C2. 요일 정합성**

`trip-brief.json`의 `day_map`을 기준으로 모든 요일 표기를 대조한다.

점검 대상: 페이지 제목, 개요 문단, 타임라인 표, 일정 요약 표, 캘린더 이벤트, 지도 페이지의 날짜 라벨.

```bash
python3 -c "
import json,datetime
b=json.load(open('/tmp/TRIP/trip-brief.json'))
W='월화수목금토일'
for d in b['day_map']:
    real=W[datetime.date.fromisoformat(d['date']).weekday()]
    flag='' if real==d['weekday'] else '  ← 불일치'
    print(f\"Day {d['day']} {d['date']} 기재={d['weekday']} 실제={real}{flag}\")
"
```

**한 곳이라도 틀리면 전 페이지를 점검한다.** 요일 오류는 국지적으로 발생하지 않는다.

---

**C3. 하위 페이지 생존 확인**

메인 페이지의 자식 페이지가 아카이브되지 않았는지 확인한다.

```
각 page_id 에 대해 fetch → "Can't edit block that is archived" 또는 조회 실패 시 아카이브됨
```

아카이브된 경우 **API로 복구되지 않는다.** `notion-move-pages`는 "already in the target location"만 반환한다. 사용자에게 다음을 안내한다.

> 노션 좌측 하단 **휴지통(Trash)** → 해당 페이지 우클릭 → **복원(Restore)**

---

**C4. 사실 오류**

특히 다음 항목은 페이지 간 교차 검증한다.

- 날짜 산술 (박수 = 종료일 − 시작일)
- 차량 픽업/반납 날짜가 모든 페이지에서 동일한가
- 숙박 일수 합계 = 여행 일수 − 1
- 비용 표의 소계·합계가 실제로 맞는가
- 전화번호 형식과 자릿수
- 운영 시간·요금이 공식 출처와 일치하는가

---

### S2 — 중요 (수정 권장)

**C5. 스팟당 이미지 수**

`policies.min_images_per_spot` 미만인 스팟을 나열한다. 소제목(`###`)이 있으면 소제목마다 이미지가 있어야 한다.

**C6. 이미지 URL 유효성**

```bash
for u in $(cat /tmp/TRIP/assets/image_urls.txt); do
  echo "$(curl -s -o /dev/null -w '%{http_code}' -L --max-time 20 "$u") $u"
done | grep -v '^200'
```

200이 아닌 항목은 `travel-image-search`로 대체 이미지를 찾아 교체한다.

**C7. 지도 섹션 존재**

각 날짜 페이지에 다음이 모두 있는가.
- `## 🗺️ Day N 지도` 헤딩
- `<embed src="https://maps.google.com/maps?...&output=embed">`
- 📱 모바일 내비 딥링크
- 스팟별 좌표 링크 표

**C8. 좌표 유효성**

모든 좌표가 여행 지역 바운딩 박스 안에 있는지 확인한다. 부호 누락(`-110` → `110`)과 자릿수 오타를 잡아낸다.

```python
def in_box(lat, lon, box):
    return box['s'] <= lat <= box['n'] and box['w'] <= lon <= box['e']
```

**C9. 콘텐츠 완결성**

각 스팟에 다음 5개가 모두 있는가: 관람 포인트 / 역사·유래 / 주차 안내 / 추천 시간대 / 현지 팁.

---

### S3 — 개선 (여유 있으면)

**C10. 문체** — `moai-content:humanize-korean` 기준. 번역투("~를 통해", "~에 대해", "~에 있어서"), 이중 피동, AI 관용구("결론적으로", "본질적으로", "~라 할 수 있다") 제거.

**C11. 링크 무결성** — 노션 내부 링크, 외부 공식 사이트 링크가 살아 있는가.

**C12. 접근성 정보** — 고령자·유아 동반 시 필요한 정보(경사도, 보행 거리, 화장실 위치, 휠체어 접근)가 있는가.

## 병렬 실행

페이지 수가 많으면 Agent tool로 페이지별 감사를 병렬화한다. 단, **수정은 순차로 한다.** 동일 페이지에 동시에 쓰면 충돌한다.

```
Agent 1: Day 1~4 감사 (읽기만)
Agent 2: Day 5~8 감사
Agent 3: Day 9~11 + 참고 자료 감사
        ↓
   findings 병합 → 메인 컨텍스트에서 순차 수정
```
