# travel-plan-intake (폐지됨 — travel-intake 사용)

이 스킬은 **v3.2 재작성에서 `travel-intake`로 통합·개편**되었습니다. `skills/travel-intake/SKILL.md`를 대신 사용하세요.

여행 계획 파싱/대화형 창조 기능은 `travel-intake`가 6개 블록 질문 구조와 `trip-brief.json` 단일 진실 공급원(SSOT) 생성 기능으로 이어받았습니다.

이 파일은 과거에 이 이름으로 스킬을 직접 참조한 워크플로우와의 하위 호환을 위해서만 남겨둡니다. 새 작업에서는 이 스킬을 호출하지 말고 `travel-intake`로 진행하세요.

자세한 변경 이력은 저장소 루트의 `UPDATES.md`를 참고하세요.
