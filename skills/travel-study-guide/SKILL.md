# Travel Study Guide (가족 예습 가이드)

이 플러그인의 존재 이유: **여행 전에 서현이와 선미가 자료를 미리 리뷰하고 현장에서 더 깊이 즐기는 것.** 따라서 스팟별 콘텐츠는 "정보 요약"이 아니라 "읽을거리" 수준의 깊이여야 한다.

## 산출물: 2종 예습 페이지 (Notion 서브 페이지)

### A. 🎓 서현이 코너 (아이용 — 초등 4학년 눈높이)

여행 메인 페이지 하위에 생성. 스팟당 아래 반복 단위:

```markdown
## {이모지} {스팟명} — {한 줄 별명}
![검증된 실사 이미지]

> 🌟 서현이가 알면 더 재밌어: {놀라운 팩트 1문장 — 숫자·비교 활용
> 예: "이 협곡은 서현이 학교 운동장 4,000개를 이어붙인 깊이야!"}

{스토리텔링 3~5문단: 존댓말 아닌 다정한 반말체.
 - 이 장소가 어떻게 생겨났는지 (지질/역사) — 만화적 비유로
 - 여기서 무엇을 보게 될지 — 시각·청각·촉각 묘사
 - 옛날 사람들(원주민·개척자)의 이야기}

### 🤔 호기심 박스
Q. {과학·역사 질문 1개} 
A. {설명 — 학교에서 배운 것과 연결}

### ✏️ 미리 퀴즈 (현장에서 답 찾기!)
- [ ] Q1. {현장에서 직접 관찰해야 풀 수 있는 문제}
- [ ] Q2. {레인저·표지판에서 답을 찾는 문제}
- [ ] Q3. {가족에게 설명해보기 미션}
```

마지막 섹션:
- `## 🏅 Junior Ranger 예습` — 해당 공원 프로그램 소개, 예상 활동(웹 리서치로 실제 워크북 내용 확인), 배지 수집 현황(메모리의 누적 기록 반영), 선서문 미리 연습
- `## 📖 여행 단어장` — 현장에서 만날 영어 단어 10개 (예: canyon, erosion, ranger, permit)

### B. 👩 부모 브리핑 (선미용 — 실전 중심)

```markdown
## Day별 핵심 브리핑
| Day | 꼭 알아야 할 것 | 리스크 | 백업 플랜 |

## 스팟별 실전 노트 (스팟당)
- **왜 가는가**: 이 스팟의 핵심 가치 2문장
- **동선·체력**: 주차→포인트 도보거리, 화장실 위치, 그늘 유무
- **서현이 포인트**: 아이가 지루해할 구간과 대응 (스낵 타이밍, 미션 활용)
- **안전**: 절벽·야생동물·온도 등 이 스팟 고유 위험 + 수칙
- **놓치기 쉬운 것**: 리뷰에서 뽑은 "아는 사람만 아는" 포인트 2~3개
- **한국어 후기**: 네이버 블로그 검색어 + 대표 후기 링크 1~2개
```

## 콘텐츠 품질 기준

1. **깊이**: 스팟당 아이용 800자 이상 + 부모용 500자 이상. 여행 개요 문장 재활용 금지 — 예습 페이지는 새로 집필.
2. **정확성**: 지질 연대·역사 사실·프로그램 운영 여부는 WebSearch로 확인, 출처 URL을 부모 브리핑에 각주로. 불확실하면 "현장 확인 필요".
3. **아이 맞춤**: 서현이 학년(초4)·기존 배지 이력·관심사를 메모리에서 로드해 비유와 난이도 조정.
4. **연결성**: Day 페이지의 스팟 섹션에서 예습 페이지 해당 섹션으로 페이지 멘션(`[[...]]`) 상호 링크.

## 생성 워크플로우

1. plan JSON + travel-research 결과(`/tmp/{여행지}_enriched.md`) 로드
2. 스팟이 많으면 Agent tool로 Day별 병렬 집필 (톤 가이드를 각 Agent에 동일하게 전달)
3. notion-travel-page 규칙대로 서브 페이지 2개 생성 (아이콘: 🎓, 👩) — 메인 페이지 "📂 가이드" 섹션의 "🎓 아이 코너 / 🚗 부모 전용" 그룹에 링크
4. 이미지가 필요한 섹션은 travel-image-search(실사) 또는 travel-image-generator(`kids-magazine`, `encyclopedia-infographic` 스타일) 활용
5. 완성 후 사용자에게: "출발 N주 전 가족 예습 일정" 제안 (예: 3주 전 서현이 코너 1회독, 1주 전 퀴즈 풀기) — 원하면 캘린더에 예습 이벤트 등록 (travel-calendar-sync)

## PDF 내보내기 (선택)

이동 중 오프라인 열람용으로 요청 시: 예습 페이지를 마크다운으로 추출 → 한글 폰트 임베딩 PDF 생성(moai-office:pdf-writer 또는 make-pdf 계열 스킬) → 파일 전달.
