# Notion Travel Page Creator v3

사용자의 실제 노션 워크스페이스에서 검증된 템플릿(아이슬란드·옐로스톤·멕시코 페이지 공통 구조)을 표준으로 재현한다.

**참조 원본**: 허브 페이지 "여행 관련" `1b502c77-e2c9-80d3-ae86-ec6e811b5241` — 새 여행 메인 페이지는 기본적으로 이 허브 아래 "Doing" 섹션에 생성한다 (다른 부모를 원하면 사용자 확인).

## 전역 블록 문법 규칙 (사용자 워크스페이스 컨벤션)

| 규칙 | 내용 |
|------|------|
| 헤딩 | **H1 금지** — 최상위 섹션은 H2(이모지 접두), 하위는 H3 |
| 강조 블록 | **callout 대신 quote(`>`)** 일관 사용 (요약 헤더·감성 인트로·경고 모두) |
| 테이블 | header-row 필수. 열 구성 재사용: `Day/날짜/이동/핵심 경험/잠자리` |
| 체크리스트 | 짐·예약·미션은 전부 to_do 블록 |
| 상태 표기 | ✅ 완료 / ⏳ 필요 이모지를 셀 안에 |
| 수치 강조 | 금액·시각·안전수치는 **bold**, 비용 테이블에 합계 행 + 인당 환산 |
| 구분 | 대섹션 사이 divider(`---`) 필수 |
| 페이지 아이콘 | 모든 페이지에 이모지 아이콘 필수 |
| 상호 링크 | 관련 페이지는 인라인 멘션 `[[페이지명]]` |
| 메타 | 페이지 말미 quote에 `작성: YYYY-MM-DD · 최종 갱신: YYYY-MM-DD` |

## 페이지 구조

### 여행 메인 페이지 (블록 순서 고정)

```
icon: {여행 이모지} / title: "{이모지} {연도} {여행명} ({M/D–M/D})"
1. quote — 한 줄 요약: 기간(요일)·박수·출발지·인원·테마
2. 히어로 이미지 1장 + 캡션 (이미지 규칙은 아래 참조)
3. H2 "🎯 이 여행이 특별한 이유" — 불릿 4~6개 (이모지+bold 키워드)
4. divider
5. H2 "🗺️ 한눈에 보기" — [동선 지도 이미지 +] Day별 요약 테이블(Day|날짜|이동|핵심 경험|잠자리)
   + Day별 구글맵 경로 링크 열 (travel-maps-integration 산출)
6. H2 "✈️ 항공·교통" — 불릿 (편명·시각 bold)
7. H2 "🏨 숙소" — 테이블(Day|숙소|가격|결제 ✅/⏳) + 합계 행
8. divider
9. H2 "🎯 핵심 예약·체크리스트" — to_do (예약 마감·오픈 시각 명시)
10. H2 "🌡️ 기후 요약" — 테이블(지역|낮|밤|비고) + 준비물 한 줄
11. [국립공원 여행 시] H2 "🏅 Junior Ranger 챌린지" — numbered + quote 경고
12. [해외 여행 시] H2 "⚠️ 일반 주의사항" — H3 소분류(입국/음식/교통/안전/날씨/결제) + 📞 연락처 테이블
13. divider
14. H2 "📂 가이드 (하위 페이지)" — H3 그룹: 📅 날짜별 / 🎓 아이 코너 / 🚗 부모 전용
15. H2 "💎 출발 전 핵심 N가지" — numbered 3~6개
16. 말미 quote (감성 한 줄 + 작성·갱신 날짜)
```

### Day 서브 페이지 (아이 중심 + 실무 통합형)

```
icon + title: "{이모지} Day {N} · {M/D}({요일}) — {출발지} → {경유} → {도착지}"
1. quote — 아이에게 말 거는 오늘의 인트로
2. 오늘의 대표 이미지 + 캡션
3. H2 "🎯 오늘의 미션 (서현이용)" — to_do 3~4개 (게이미피케이션)
4. H2 "📋 오늘의 흐름" — 불릿 3개: 이동 경로 / 주행 km·운전시간 / 잠자리
   + [🗺️ 오늘 전체 경로 열기](구글맵 경로 딥링크)
5. H2 "⏰ 타임라인" — 테이블(시간|장소·활동|부모 메모), 시간 bold
6. divider
7. [스팟 반복 단위 × N]:
   H2 "{이모지} {스팟명} — {한 줄 별명}"
   이미지 1장 (검증 필수)
   > 🌟 서현이가 알면 더 재밌어: {팩트 1문장}
   기본정보 테이블 (주소|운영|입장료|소요|난이도|📍 지도 링크)
   불릿: 볼거리·팁·주의 (안전은 bold)
   H3 "🤔 서현이 호기심 박스" — 과학 Q&A 한 문단
   {6가지 보강 블록 — travel-content-enrichment 담당}
   > 🗣️ 방문자 리뷰 하이라이트 — travel-spot-reviews 담당
8. H2 "🛏 {숙소명}" — quote + 불릿(위치/체크인/시설) / H2 "🍽 식단" — 점심/저녁/백업
9. H2 "💰 예상 비용 (3인)" — 테이블(항목|금액) + 합계
10. H2 "📝 한국어 블로그 검색어" — 불릿 3개
11. H2 "📝 부모 메모" — 불릿 + 마무리 quote "오늘의 한 마디"
```

### 유틸 서브 페이지 5종 (각 담당 스킬이 콘텐츠 생성)

| 페이지 | 구조 핵심 | 담당 |
|--------|-----------|------|
| 🎒 짐싸기 | quote 원칙 → H2 카테고리 → H3 소분류 → to_do `품목 ×수량` (+현지 구입처·가격) | travel-packing-list |
| 💰 예상 비용 | 카테고리 합계 테이블(범위금액+예비비 10%+총계·인당) / 숙소 세부(✅⏳) / 일자별 / 💡 절약팁 | trip-budget |
| 🚨 긴급 정보 | ☎️ 전화 테이블 → 🏥 Day 구간별 H3 병원 → 위험유형별 H2 수칙 | travel-emergency-info |
| ✈️ 교통·예약 | 항공 H3(출/도/귀) → 렌터카 H3 → 🎫 예약 테이블(항목|일시|예약처 링크|가격|주의) → 📅 D-데이 타임라인 | travel-transport-info |
| ✅ 예약 체크리스트 | H2 = D-구간(D-365→D-1) + 하위 to_do(오픈 시각·예약처 링크 내장) | travel-transport-info |

추가: 🎓 서현이 코너 + 👩 부모 브리핑 — travel-study-guide 담당.

## 이미지 삽입 규칙 (오류 예방 — 필수 준수)

1. **이 스킬은 이미지 URL을 직접 만들지 않는다.** 모든 이미지는 travel-image-search / travel-image-generator가 검증·제공한 것만 사용.
2. 페이지 생성 시점에 이미지가 아직 없으면 **플레이스홀더 텍스트를 넣지 말고 이미지 라인을 생략** — 이후 image-search가 스팟 H2 바로 아래에 삽입한다 (빈 이미지 블록·깨진 URL 방지).
3. 삽입 방식 우선순위: ① `notion-create-attachment` → `![캡션](file-upload://...)` ② 검증된 직링크 embed. `file-upload://` 소스는 발급 1시간 내 배치.
4. 이미지 마크다운을 `update_content`로 교체할 때 old_str은 URL 전체가 아닌 **고유 접두 부분만** 사용 (긴 URL 매칭 실패 예방).

## 생성 워크플로우

1. **enhanced-markdown-spec 확인**: 생성 전 MCP 리소스 `notion://docs/enhanced-markdown-spec`을 읽어 문법 확인 (추측 금지)
2. 허브 페이지 fetch → 기존 동일 여행 페이지 존재 시 사용자에게 덮어쓰기/병합/취소 확인
3. `notion-create-pages`로 메인 페이지 생성 (콘텐츠를 한 번에 — update 반복 최소화)
4. Day 페이지 N개 + 유틸 페이지를 생성 (병렬 가능하면 한 호출에 여러 페이지)
5. 생성 직후 각 페이지 fetch로 렌더링 확인 — 테이블 깨짐·이스케이프 문제(`~` → `\~`) 점검
6. 페이지 ID 매핑을 `/tmp/{여행지}_notion_ids.json`에 저장 + 메모리(`user_travel_*_notion.md`) 갱신

## update_content 오류 대응 (v2 검증된 노하우 유지)

1. 업데이트 직전 반드시 fetch로 현재 내용 확인
2. old_str은 짧고 고유하게, 이모지 포함 매칭 회피 (이모지 직후 텍스트로)
3. "No matches found" → 재fetch → 더 짧은 문자열 → 최후 replace_content
4. 한 번에 너무 많은 블록을 update하지 말고 섹션 단위로 분할
