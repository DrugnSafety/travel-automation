# Travel Content Enrichment

이미 생성된 여행 Notion 페이지의 각 관광 스팟에 6가지 카테고리의 상세 콘텐츠를 추가하여 완성도 높은 여행 가이드로 보강하는 스킬입니다.

## 필요 도구

- **Notion MCP**: `fetch`, `notion-update-page`
- **WebSearch**: 추가 리서치가 필요한 경우
- 입력: travel-research 스킬의 출력 파일 또는 웹 검색 결과

## 6가지 콘텐츠 블록

각 관광 스팟에 다음 6가지 블록을 blockquote 형식으로 추가합니다:

### 블록 형식 (Notion Enhanced Markdown)

```markdown
> 🌍 **역사/문화적 배경**
> {최소 3-5문장의 상세 설명. 지질학적 형성 과정, 역사적 사건, 문화적 의의 등}

> 👨‍👩‍👧 **아이와 함께하는 팁**
> • {연령대별 적합도}
> • {안전 주의사항}
> • {학습 포인트}
> • {접근성 정보}

> 📸 **포토 스팟 & 촬영 가이드**
> • **최적 시간**: {시간대와 이유}
> • **카메라 설정**: {ISO, 조리개, 셔터스피드}
> • **렌즈 추천**: {초점거리와 용도}
> • {구도 팁}

> 🍽️ **맛집 & 음식 추천**
> • **{레스토랑명}** ({유형}): {추천 메뉴} — ⭐{평점}, ${가격대}
> • **{레스토랑명}** ({유형}): {추천 메뉴} — ⭐{평점}, ${가격대}

> 💰 **예상 비용**
> • 입장료: ${금액}/인 (아이 할인: {정보})
> • 주차: ${금액}
> • 장비/대여: ${금액}
> • 💡 할인 팁: {할인 정보}

> 🔍 **한국어 블로그 검색어**: "{키워드1}", "{키워드2}", "{키워드3}"
```

## 보강 워크플로우

### Step 1: 현재 페이지 내용 확인

```
Notion fetch로 대상 페이지의 현재 내용을 가져옵니다.
- 각 스팟의 현재 설명 수준 파악
- 이미 보강된 블록이 있는지 확인 (중복 방지)
- 업데이트에 사용할 고유한 매칭 문자열 식별
```

### Step 2: 리서치 콘텐츠 준비

travel-research 스킬의 출력 파일이 있으면 해당 내용을 사용합니다.
없으면 WebSearch로 직접 리서치를 수행합니다.

### Step 3: 보강 콘텐츠 삽입

각 스팟의 기존 내용 뒤에 6가지 블록을 추가합니다.

**삽입 위치 전략:**
1. 각 스팟 섹션의 마지막 내용(테이블, 팁, 주의사항 등) 바로 뒤
2. 다음 섹션의 `---` 구분선 바로 앞
3. 매칭 문자열: 섹션 구분선과 다음 섹션 제목을 포함

**update_content 패턴:**
```json
{
  "old_str": "{스팟 마지막 내용}\n---\n## {다음 섹션 제목}",
  "new_str": "{스팟 마지막 내용}\n\n{6가지 보강 블록}\n\n---\n## {다음 섹션 제목}"
}
```

### Step 4: 검증

보강 후 페이지를 다시 fetch하여:
- 모든 블록이 정상 삽입되었는지 확인
- 마크다운 렌더링이 올바른지 확인
- 기존 콘텐츠가 손상되지 않았는지 확인

## 콘텐츠 작성 가이드

### 여행 유형별 커스터마이징

**자연 경관 (국립공원, 협곡 등)**
- 🌍: 지질학적 형성 과정, 암석/지층 특징, 연대
- 📸: 자연광 활용법, 광각 렌즈 위주

**도시 관광 (유럽, 아시아 도시 등)**
- 🌍: 역사적 사건, 건축 양식, 문화적 의의
- 📸: 야경 촬영법, 거리 사진 팁

**해변/리조트**
- 🌍: 해양 생태계, 산호초 보전
- 📸: 일출/일몰, 수중 촬영, 드론 촬영 팁

**문화 체험 (사원, 박물관 등)**
- 🌍: 종교적/문화적 의의, 건축 양식
- 📸: 실내 촬영법, 플래시 제한 대응

### 아이 연령별 기준

| 연령 | 트레일 난이도 | 거리 | 특별 주의 |
|------|------------|------|---------|
| 0-3세 | 유모차 가능한 곳만 | 1km 이내 | 그늘, 수유실 |
| 4-7세 | 쉬움 | 3km 이내 | 흥미 유발 포인트 |
| 8-12세 | 보통 | 5km 이내 | 학습 활동 연계 |
| 13세+ | 어려움 가능 | 제한 없음 | 도전 의식 자극 |

## 문자열 매칭 주의사항

Notion의 `update_content`에서 가장 흔한 오류는 문자열 매칭 실패입니다.

**예방 방법:**
1. 업데이트 직전에 반드시 `fetch`로 현재 내용 확인
2. `old_str`은 가능한 짧고 고유한 문자열 사용
3. 한국어 인코딩 문제가 의심되면 ASCII 위주 문자열로 매칭
4. 이모지를 포함한 매칭은 피하고, 이모지 직후의 텍스트로 매칭
5. Notion이 `~`를 `\~`로 이스케이프하므로 주의

**실패 시 대응:**
1. 페이지 재fetch → 정확한 현재 내용 확인
2. 더 짧은 고유 문자열로 재시도
3. 최후의 수단: `replace_content`로 전체 섹션 교체
