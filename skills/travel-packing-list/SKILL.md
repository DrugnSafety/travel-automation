# Travel Packing List

여행 조건에 맞는 맞춤형 짐 싸기 체크리스트를 생성하는 스킬입니다.

## 입력 정보

| 항목 | 필수 | 예시 |
|------|------|------|
| 여행지 | ✅ | 미국 남서부, 일본 도쿄 |
| 여행 기간 | ✅ | 12일 |
| 여행 시기 | ✅ | 4월 중순 |
| 인원 구성 | ✅ | 성인 2명 + 5세 아이 1명 |
| 여행 유형 | ✅ | 로드트립, 도시관광, 리조트 등 |
| 주요 활동 | 선택 | 트레킹, 수영, 스키 등 |

## 체크리스트 카테고리

### 1. 서류/필수품
- 여권/비자, 여행자보험 서류, 국제운전면허증
- 항공권/예약 확인서 (프린트 + 디지털)
- 신용카드/현금/환전
- 여행지 SIM카드 또는 로밍 정보

### 2. 의류 (기후 기반)
- 웹 검색으로 여행지의 해당 시기 평균 기온, 강수량 확인
- 낮/밤 기온차 고려
- 활동별 적합한 의류 (트레킹복, 수영복 등)
- 레이어링 전략 제시

### 3. 전자기기
- 충전기/보조배터리
- 여행지 전압/플러그 어댑터 (웹 검색으로 확인)
- 카메라/삼각대 (포토 스팟이 있는 여행 시)

### 4. 건강/위생
- 상비약 (여행지 특성 반영)
- 자외선 차단제 (SPF 수준은 여행지 기후에 따라)
- 모기약/벌레퇴치제 (열대 지역)

### 5. 아이 용품 (아이 동반 시)
- **영유아 (0-2세)**: 기저귀, 분유/이유식, 유모차, 아기띠
- **유아 (3-5세)**: 간식, 장난감/색칠공부, 아동용 자외선 차단제, 차량용 카시트
- **초등 (6-12세)**: 학습 도구, 게임/책, 수영용품
- **청소년 (13+)**: 개인 전자기기, 활동 장비

### 6. 여행 유형별 특수 아이템

**로드트립**: 차량용 충전기, 쿨러백, 간식, 도로 지도(백업), 타이어 펑크 키트
**도시관광**: 편한 워킹슈즈, 도난방지 가방, 우산, 대중교통 카드
**리조트/해변**: 수영복, 래쉬가드, 비치타월, 스노클링 장비, 방수팩
**트레킹/자연**: 등산화, 등산 스틱, 헤드랜턴, 방수 재킷, 구급키트
**크루즈**: 정장(디너용), 멀미약, 자석훅(캐빈용), 방수백

## 출력 형식

체크리스트는 Notion 페이지 또는 마크다운으로 출력합니다:

```markdown
## ✅ 짐 싸기 체크리스트

### 📄 서류/필수품
- [ ] 여권 (유효기간 6개월 이상 확인)
- [ ] ESTA 승인서 프린트
- [ ] 국제운전면허증
...

### 👕 의류 (4월 남서부 기준: 낮 20-30°C, 밤 5-10°C)
- [ ] 긴팔 티셔츠 × 4
- [ ] 반팔 티셔츠 × 4
- [ ] 경량 패딩 또는 플리스 × 1
...
```

## 워크플로우

1. 여행 조건 수집 (입력 정보 확인)
2. 웹 검색으로 여행지 기후/전압/비자 정보 확인
3. 카테고리별 아이템 생성
4. 인원별 수량 조정
5. Notion 페이지에 체크리스트 추가 또는 별도 마크다운 생성
