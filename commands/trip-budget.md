사용자가 여행 예산/비용 계획을 요청했다.

## 실행 절차

1. 인자 확인: `$ARGUMENTS`에서 여행지, 기간, 인원 정보를 파싱한다.

2. 누락된 정보가 있으면 AskUserQuestion으로 수집:
   - 여행지 및 경로
   - 여행 기간
   - 인원 구성
   - 여행 유형
   - 예산 수준 (절약형 / 중간 / 여유형)
   - 통화 (KRW, USD 등)

3. 웹 검색으로 최신 가격 정보를 수집:

   **항공**: 출발지~목적지 항공편 가격대 (Kiwi.com MCP 사용 가능 시 활용)
   **숙박**: 호텔/에어비앤비 가격대 (Trivago MCP 사용 가능 시 활용)
   **렌트카**: 일일 렌트비 (해당 시)
   **식비**: 현지 식사 가격대 (아침/점심/저녁)
   **입장료**: 주요 관광지 입장료
   **교통비**: 현지 교통, 주유비, 톨비
   **기타**: 여행자보험, 로밍/SIM, 쇼핑 예비비

4. 카테고리별 비용을 일별로 정리한 예산표를 생성한다:

```
| 카테고리 | 단가 | 수량/일수 | 소계 |
|----------|------|-----------|------|
| 항공편 (왕복) | $350/인 | ×3명 | $1,050 |
| 렌트카 (12일) | $60/일 | ×12일 | $720 |
...
| **총 예상 비용** | | | **$5,200** |
```

5. 출력 방식:
   - xlsx 스킬이 사용 가능하면 Excel 스프레드시트로 생성
   - 아니면 Notion 페이지의 예산 섹션에 테이블로 추가
   - 또는 마크다운 테이블로 출력

6. 환율 정보도 함께 제공 (현재 환율 기준 원화 환산 금액 포함).
